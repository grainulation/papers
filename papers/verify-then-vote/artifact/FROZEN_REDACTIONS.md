# Public redactions and frozen provenance

The v4, v5 and v6 freeze records preserve the original study hashes. Current public files differ only where the exact original/published pair is listed below. Redactions remove private process references, machine paths and binary diagnostic build prefixes; runtime configuration uses environment variables or PATH. Public runtime names use `OVERTURN_*`, with historical environment names retained as fallback inputs. They do not change hypotheses, thresholds, benchmark answers, support labels or reported scientific counts.

These files must not be described as byte-identical originals. The frozen study records describe analysis timing and original file identities, not earlier public releases. Current source reconstruction validates the original freeze maps against the published files, accepts only the exact listed pairs, records actual binary identities, and compares decisions with the published results. See [README.md](README.md) for commands.

## Verify the public input set

From this artifact directory:

```sh
python3 reproduction/portable.py --help
```

The portable reconstruction command checks v4/v5/v6 freeze entries before running. A change not covered by an exact path and original/published hash pair fails verification. The v4 binary is recorded separately in its freeze record and is checked too.

## Binary and runtime scope

The two historical macOS arm64 executable copies have equal-length substitutions of their embedded build-home prefix and renewed ad-hoc signatures. Executable instructions are unchanged, but their bytes and hashes differ from the original binaries. The primary public reproduction path builds the reducer from source instead. Reproduction receipts identify the original, published and rebuilt binary hashes separately.

Public tool configuration uses `OVERTURN_CORPUS_CACHE`, `OVERTURN_CLAUDE_BIN`, and `OVERTURN_OLLAMA_LOG`. The corresponding `BRAN_*` variables remain fallback inputs for historical launch configurations; the public names take precedence. Defaults remain the artifact corpus cache, `claude` on PATH, and `ollama.log` in the working directory. Model and client identity checks still apply; future checker calls identify their changed source rather than inheriting a frozen identity. Recollection is a new experiment and requires the documented models and corpus inputs. It is not needed for source reconstruction from sealed records.

## Historical identifiers

Content-addressed format tags and earlier software names remain unchanged because they are part of sealed data, not local checkout references. `v3/SWARM3_DESIGN.md` resolves to the included `v3/DESIGN.md`. A historical preregistration mentions an earlier manuscript draft; the published manuscript is `../paper.pdf`, and that draft is not an input needed by reconstruction.

The 300 second-pool futility-slice links now use relative targets inside this artifact. Each target was byte-compared with the original link destination before replacement. No raw model response changed.
